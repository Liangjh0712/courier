# Courier

在 Mac 上的一个浮动输入框里写好要发的话，连同截图一起，发给当时在最前面的 App：终端里的 Claude Code、飞书、浏览器都行。

它像输入法一样不挑 App：发送时把内容放上剪贴板，替你按 ⌘V（终端里贴图片用 ⌃V），最后按回车，然后把剪贴板还原。

## 用法

- 点一下要发往的窗口，再点 Courier 的输入框写字。顶部显示发往哪个 App。
- 输入框是一行卡片：左边是发往的 App，右边是加图片、历史、清空、收起和发送按钮。
- Enter 或发送按钮：填入 App 并按回车。⌥Enter 或发送键左边的「只填入」按钮：只把内容填进 App，不按回车，留给你在 App 里再看一眼或接着改。⇧Enter 换行。
- ⌘V 贴截图，或者把图片拖进来。截图以缩略图嵌在文字里，点一下看大图；发送时文字和图片按顺序送出。
- 默认一行高，拖边框调宽度和高度，大小会记住；字多了在框里换行、上下滚动。不用时变淡，鼠标移上去恢复。
- 历史按钮或 ⌘↑ / ⌘↓ 翻看发过的内容。清空按钮或 ⌘K 清空，⌘Z 撤销。
- 发送目标：
  - 默认跟随你点过的前台 App。截图工具、录屏工具栏这类浮层不会抢走目标。
  - 点左边的 App 图标，可以锁定发往这个 App（⌘L 同），可以从运行中的 App 里手选，也可以按 App 设置贴图片用 ⌘V 还是 ⌃V，发送用回车还是 ⌘回车。终端默认用 ⌃V 贴图片。
- 发送途中切到别的 App，内容仍然发往原来的目标，发完回到你切去的 App。
- 收起按钮、Esc 或 ⌘W 收起：输入框缩成它左端的悬浮球，有草稿时显示红点。拖动悬浮球，展开的输入框就在新位置；拖动输入框，收起的悬浮球也跟着在那里。也可以点 Dock 图标找回。
- 草稿、截图、历史都存在本地，重启不丢。

## 权限

要在「系统设置 › 隐私与安全性 › 辅助功能」里打开 Courier，它才能替你按键。

## 构建

需要 Xcode（Swift 6）和 macOS 14 以上。

```sh
swift test
scripts/build.sh --install
```

辅助功能权限跟签名绑定。默认是临时签名，每次构建签名都会变，权限要重新授。设置 `SIGN_IDENTITY` 用一个固定的签名身份，权限就能一直保留，见 `scripts/build.sh` 开头的说明。

日志在 `~/Library/Logs/Courier.log`，每次发送的每一步都有记录。
